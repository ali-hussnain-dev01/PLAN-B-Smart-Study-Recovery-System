# PLAN B – Smart Study Recovery System

A Python-based desktop application designed to help students manage missed study time and recover their study targets through smart planning.

## Features
- Subject Management
- Smart Recovery Planner
- Subject-wise Recovery Targets
- Study Progress Tracking
- Books Tracker
- Exam Countdown
- Overload Alerts

## Technologies Used
- Python
- Tkinter
- SQLite

## How It Works
PLAN B helps students track missed study time and create recovery targets instead of letting unfinished study tasks pile up.
